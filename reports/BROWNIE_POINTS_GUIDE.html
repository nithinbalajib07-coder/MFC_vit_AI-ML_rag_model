1. Hybrid Retrieval (Semantic AI + Keyword Search)

The Problem It Solves

  • Dense Vector Search understands concepts, but stumbles on exact campus acronyms (SMUSA, ITSS) and room codes (Loyola Academic 268).
  • BM25 Keyword Search matches exact tokens, but fails when students use synonyms (e.g., "Where can I buy lunch?" when the text says "cafeteria").
  • Hybrid Retrieval blends both so students get accurate answers regardless of phrasing.
RRF Score = [ 0.6 / (60 + Dense Rank) ] + [ 0.4 / (60 + Keyword Rank) ] 
# src/hybrid_retriever.py
dense_hits = self.vector_store.search(query_vec, top_k=top_k * 2)
sparse_hits = self.bm25.search(query, top_k=top_k * 2)

for rank, hit in enumerate(dense_hits, 1):
    rrf_scores[hit["doc_id"]] += 0.6 / (60 + rank)
for rank, hit in enumerate(sparse_hits, 1):
    rrf_scores[hit["doc_id"]] += 0.4 / (60 + rank)

2. Cross-Encoder Passage Reranking

How It Works

A Cross-Encoder model (cross-encoder/ms-marco-MiniLM-L-6-v2) reads the question and candidate passage side-by-side, analyzing word-by-word connections. Its raw scores are scaled to calibrated confidence percentages:

Confidence % = 1 / (1 + e^(-Logit Score / 2.0))

4. Answer Faithfulness & Source Correctness

The evaluation suite decomposes generated responses into atomic statements and tests them against the retrieved source facts. It includes stress-tests that deliberately corrupt numbers, invent facts, or spoof citation IDs to verify that unfaithful claims are immediately caught.
